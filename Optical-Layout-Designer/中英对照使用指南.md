# Optical Layout Designer · 中英对照使用指南

**第一次使用 | First session**  
在本机项目目录双击 [Start-Designer.cmd](Start-Designer.cmd)，打开示例原理图。按 Ctrl+1 查看光路，Ctrl+2 查看同一组元件在台面上的位置，Ctrl+3 查看安装高度。  
Double-click the launcher above to open the example. Use Ctrl+1 to trace the beam, Ctrl+2 to locate the same components on the board, and Ctrl+3 to inspect their mounting heights.

## 从空白台面画出第一条光路 | Build your first beam path

| 步骤 | 中文操作 | English instructions |
|---|---|---|
| 1 · 台面 / Board | 按 Ctrl+N 新建。在 **File → Board size, holes and shape…** 设置尺寸和孔阵。初次练习可选 **1" grid**，对应一英寸孔距的面包板。 | Press Ctrl+N. Under **File → Board size, holes and shape…**, set the dimensions and hole pattern. For this exercise, choose **1" grid**, a breadboard with one-inch hole spacing. |
| 2 · 放置 / Place | 按 Ctrl+1 进入 **Schematic**。从左侧选择一个反射镜符号，在画布上单击放置。用相同方法再放一面反射镜和一个透镜。这里的位置只为读图方便。 | Open **Schematic** with Ctrl+1. Select a mirror symbol on the left and click the sheet to place it. Add a second mirror and a lens. Space them for readability. |
| 3 · 连线 / Connect | 按 B，依次点击第一面镜、第二面镜、透镜，再按 Esc 结束。应看到两段相连的光束。若需要在已有光束中插入元件，放置时直接点在线上。 | Press B and click the first mirror, the second mirror, then the lens. Press Esc. You should see two connected beam segments. To insert another component, place it directly on a segment. |
| 4 · 排布 / Position | 按 Ctrl+2 进入 **Layout**。从台面下方的待放区把新元件拖到板上，按实际位置排布。默认吸附到孔位，按住 Alt 拖动可自由定位。 | Switch to **Layout** with Ctrl+2. Drag new parts from the staging strip below the board to their physical positions. Parts snap to mounting holes. Hold Alt while dragging for free placement. |
| 5 · 检查 / Inspect | 红色虚线轮廓表示元件重叠。用 **Layout → Show overlapping parts** 选出它们并调整。按 L 测距，Ctrl+L 显示光束长度。 | A red dashed outline marks overlapping parts. Select them with **Layout → Show overlapping parts** and adjust their positions. Press L to measure a distance or Ctrl+L to display beam lengths. |
| 6 · 三维 / View in 3D | 按 Ctrl+3。在三维视图中拖动旋转，滚轮缩放，Shift 加拖动平移。检查光束高度和镜架位置。若某元件显示为简化形状，查看状态栏列出的缺失模型。 | Press Ctrl+3. Drag to rotate, scroll to zoom, and Shift-drag to pan. Inspect beam heights and mount positions. If a part appears as a simple shape, check the status line for missing models. |
| 7 · 保存 / Save | 按 Ctrl+S，将练习命名为 first_layout.json。原理图与台面布局保存在同一个文件中。 | Press Ctrl+S and save the exercise as first_layout.json. One file stores both the schematic and the physical layout. |

## 编辑与交付 | Edit and export

| 目的 / Task | 中文操作 | English instructions |
|---|---|---|
| 定位同一元件 / Find a part | 在 Layout 双击元件可跳到原理图中的对应符号。 | Double-click a part in Layout to locate its symbol in the schematic. |
| 调整朝向 / Adjust orientation | 选中元件后，用 R 或 Shift+R 以 45° 为步长旋转，用方括号键以 5° 为步长微调。按 A 恢复自动朝向。 | Select a part. Use R or Shift+R for 45° steps, or the square bracket keys for 5° steps. Press A to restore automatic aiming. |
| 编辑型号 / Edit part numbers | 选中元件填写型号或订货号。Ctrl+T 打开全体元件的编辑表。 | Select a part to enter its type or part number. Press Ctrl+T to edit the parts together in a table. |
| 导出图纸 / Export a figure | 先切到要导出的原理图或台面视图，再按 Ctrl+E 导出 SVG 矢量图，或 Ctrl+Shift+E 导出 PNG 图片。 | Open the schematic or layout you want to share. Use Ctrl+E for a vector SVG or Ctrl+Shift+E for a PNG image. |
| 物料清单 / Bill of materials | Ctrl+Shift+B 查看元件、支撑杆和转接件清单。需要表格时，从 File 菜单导出 CSV。 | Press Ctrl+Shift+B to review parts, posts and adapters. Export the bill of materials as a CSV from the File menu. |

## 实验台旁记录功率 | Log power at the bench

| 步骤 | 中文操作 | English instructions |
|---|---|---|
| 建立测点 / Add a point | 在 Layout 按 M，再点一段光束。要记录光纤输出，在光纤耦合器上点击。 | In Layout, press M and click a beam. For a reading after a fiber, click its fiber coupler. |
| 录入读数 / Enter a reading | 点击测点，填写实测功率、功率计和备注。软件自动记录时间。再次点击同一测点可查看历史曲线。 | Click the point and enter the measured power, meter and notes. The app records the time. Reopen the point to inspect its history and plot. |
| 更正与备份 / Correct and back up | 如需更正，追加一条读数并注明原因。布局保存在 JSON，历史读数保存在同目录的 .logbook.sqlite 文件中；备份时复制两者。 | To correct a reading, add a new entry with an explanatory note. Back up both the layout JSON and its adjacent .logbook.sqlite file to preserve the design and measurement history. |
| 导出记录 / Export records | Ctrl+P 生成含布局图和所选测点的实验记录表。要导出全部读数，选 **File → Export power log (CSV)…**。 | Press Ctrl+P for a lab sheet with the layout and selected points. For all readings, choose **File → Export power log (CSV)…**. |

**进一步练习 | Explore another example**  
打开 [399 nm 示例](examples/demo_399nm.json) 查看带功率记录的分光板，或打开 [421 nm 实例](421nm_system/Dy1-lowpower.json) 观察更复杂的台面排布。如果程序提示选择日志而你只想浏览，选 **Open without log**。  
Open the 399 nm example to explore a distribution board with sample readings, or the 421 nm example to inspect a more complex layout. If prompted for a log while browsing, select **Open without log**.

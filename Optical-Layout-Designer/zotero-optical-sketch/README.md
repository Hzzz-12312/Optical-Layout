# 光路手绘 · Optical Sketch（Zotero 插件）

在 Zotero 条目面板里为 PDF 附件手绘光路草图，草图按附件保存在本机，并可导出为
Optical Layout Designer 能读取的原理图 JSON。

## 安装

1. Zotero 7.0 及以上（已在 Zotero 10.0.8 上验证打包格式）。
2. 打开 **工具 → 插件**（Tools → Plugins）。
3. 点右上角的齿轮 → **Install Plugin From File…**，选择项目目录里的 `Optical-Sketch-0.3.0.xpi`。
4. 选中带 PDF 附件的条目（或直接选中 PDF 附件 / 打开 PDF 阅读器），右侧条目面板会出现
   「光路手绘」分区：条目面板最右侧图标栏里那个绿色斜线图标就是它，点一下即可展开。
   选中没有 PDF 附件的条目时分区会显示一行提示，而不是整块消失。

也可用于调试：**工具 → 开发者 → Run JavaScript**，或把 `.xpi` 直接放进
`<profile>/extensions/optical-sketch@local.tools.xpi` 后重启 Zotero。

## 固定一张论文插图

1. 在 Zotero 的 PDF 阅读器里翻到要参考的插图，展开右侧「光路手绘」。
2. 点击画布上方 **论文参考图 → 框选参考图**。在同一页上用鼠标从图的一角拖到对角，松开后，截取的区域就会出现在右栏。
3. 左侧可以继续滚动、翻页、选择文字或使用翻译工具。右侧的图片始终属于这份 PDF，关闭再打开时会恢复。
4. **放大** 可以查看图中细节，点 **适应** 恢复全图。**重新框选** 会在成功截取后替换图片。按 **Esc** 或点击 **取消框选** 会保留原图。**移除** 只清除当前 PDF 的参考图。

每份 PDF 保存一张参考图，存在 Zotero 数据目录的 `optical-sketch` 文件夹内。参考图和草图分开保存，导出的光路 JSON 只包含绘图数据。

## 画图与标注

打开一篇 PDF，在右侧「光路手绘」分区选择元件，点击画布放置。每个 PDF 有一张独立的本机草图。升级时可直接安装新版，旧草图沿用原来的附件编号和坐标。

| 操作 | 用法 |
|---|---|
| 选择与移动 | 「放置元件」右边的「选择」按钮用于切回选择模式。点击元件可编辑属性，拖动元件可移位，拖动空白处可平移画布。 |
| 对齐或自由放置 | 「吸附」默认开启，间距默认 10，可选 5、10、20、40 个原理图单位。按住 Alt 放置或拖动可临时自由定位。隐藏「网格」时也可保留吸附。 |
| 重复放置、复制 | 选好元件后按住 Shift 连续点击。选中已有元件后按 Ctrl+D 或点「复制」，新元件会获得独立编号。 |
| 连续画光束和分支 | 画布中按 B，沿传播方向依次点击元件。按住 Shift 点击分束点即可从该点开始另一条支路。Esc 退出。 |
| 中途插入元件 | 选好元件后点击已有光束。原光束会拆为两段，保留方向、波长和颜色。Ctrl+Z 可撤销整个插入。 |
| 精调位置和朝向 | 选中元件后用方向键移动，Alt 加方向键按一个坐标单位微调。R 和 Shift+R 分别旋转 45° 和反向旋转 45°。 |
| 关联论文页 | 在 PDF 阅读器中选中元件或光束，点「标记当前 PDF 页」。以后点「查看 PDF 第 … 页」即可回到原处。页数按 PDF 文件页序计数。 |

快捷键在画布获得焦点时生效。选中光束后可以改名称、填写波长并选择线色，用来区分激发光、收集光和参考光。页面关联随本机草图保存。导出的 Designer JSON 包含原理图元件和连线；页码保存在 Zotero 本地草图里。

本版含 28 种元件。新增的显微物镜、样品池、二向色镜、光栅、五种滤光片、棱镜、线偏振片、电光调制器、光隔离器、相机和光谱仪使用原创二维符号。包含新增类型的 JSON 请用本版配套桌面设计器打开。桌面端用缩写表示新增元件，用位置标记表示其台面位置。

## 打包

插件源码在本目录，打包脚本只把运行期文件写进 XPI：

```
python zotero-optical-sketch/build.py
# 生成 Optical-Sketch-<version>.xpi 到仓库根目录
```

改了 `manifest.json` 的 `version` 后重新打包即可。

## Zotero 10 的插件清单要求（导入失败的常见原因）

Zotero 10 会拒绝缺少以下字段的插件，界面通常只提示“插件已损坏 / 无效”：

- `applications.zotero.id`
- `applications.zotero.update_url`
- `applications.zotero.strict_max_version`

`strict_min_version` 里不允许出现 `*`。`update_url` 指向 GitHub `main` 分支上的
本目录 `update.json`（推送后才会生效）：Zotero 检查更新时会去拉取，暂时拉不到不影响
插件安装和运行。

另外两个与版本相关的提示：

| 提示 | 含义 | 处理 |
|---|---|---|
| “…与 Zotero x.y 不兼容” | 当前 Zotero 版本不在 `strict_min_version`–`strict_max_version` 区间 | 调整 `manifest.json` 后重新打包 |
| “插件似乎已损坏 / 无法安装” | 清单缺字段、JSON 语法错误、XPI 结构不对 | 跑 `build.py`，它会在打包前校验清单 |

## 文件

| 文件 | 用途 |
|---|---|
| `manifest.json` | 插件清单（版本、ID、兼容范围、更新地址） |
| `bootstrap.js` | 生命周期入口，注册条目面板分区 |
| `editor.js` / `editor.css` | SVG 光路画布与交互 |
| `catalog.js` / `source.js` | 扩展元件符号和 PDF 来源页操作 |
| `storage.js` | 按附件读写草图、导出 Designer JSON |
| `locale/{en-US,zh-CN}/optical-sketch.ftl` | 面板标题与提示文本 |
| `build.py` | 打包脚本（不进入 XPI） |
| `update.json` | `update_url` 指向的更新清单（不进入 XPI） |
